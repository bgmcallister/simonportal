S23 CUSTOMIZATION / TINKERING — MASTER LIST
Research status: August 2026
Reddit: PERMANENTLY EXCLUDED from research sources.

RULES:
• Genuinely free
• No required subscription
• No trial
• No important/useful-feature paywall
• S23/One UI usefulness matters
• Prefer Google Play when available
• F-Droid/official GitHub/etc. acceptable
• FOSS/free-to-download alone is NOT enough
• Optional ads/paid extras must be clearly disclosed

🟢 CONFIRMED / KEEP

F-DROID
• Arcticons — ~14,700+ monochrome line icons; visual icon
  replacement. Samsung requires Theme Park to apply the pack.
• Ion Launcher — customizable replacement launcher with app
  categorization, colors, animations, icon customization and
  Smartspacer integration.
• EasyLauncher — minimalist, clutter-free productivity launcher.
• Activity Launcher — exposes installed-app activities, including
  hidden activities, and lets you create direct shortcuts.
• Termux — full Linux terminal/package environment on Android;
  Bash/Zsh, SSH, Python, Git, compilers, etc.
• Termux:API — lets Termux scripts interact with Android functions
  such as GPS, SMS, clipboard, TTS, vibration and contacts.
• Termux:Widget — puts Termux scripts/commands on the Android
  home screen as tappable shortcuts.
• FluxLinux — runs Linux desktop environments on Android; Debian,
  XFCE4/KDE, GPU acceleration, development/data-science tooling,
  Termux integration and non-root operation.
• Smart Dock — desktop-style launcher with customizable icons,
  colors, shapes, sounds, multi-window and keyboard shortcuts;
  Android 10+, no root required; Shizuku can expand permissions.

NON-F-DROID / OTHER SOURCES
• ColorBlendr — deeper Material You/dynamic-color customization
  for compatible apps; Samsung system apps retain One UI's own
  color system.
• Shizuku — system-level API bridge for compatible apps.
• SystemUI Tuner — exposes hidden Android/System UI controls.
• TapTap — back-tap gesture customization.
• Adaptive Theme — switches light/dark mode based on ambient light.
• CustomAnimator — precise animation speeds, DPI and advanced tweaks.
• Adaptive Hz — interaction-based 60/120 Hz switching for Samsung;
  offline/no ads/no tracking; MIT.
• Smart Edge — customizable edge/sidebar panel with themes, blur,
  icon customization, gestures, split-screen/freeform and tools;
  MIT; FOSS version has features unlocked.
